# Инструкция по тестированию новых функций

## Тестирование блокировки IP

### Шаг 1: Запустите приложение
```bash
python app.py
```

### Шаг 2: Проверьте блокировку
1. Откройте страницу входа
2. Введите неверный пароль 5 раз подряд
3. После 5-й попытки вы увидите сообщение о блокировке
4. Попытка входа будет заблокирована на 15 минут

### Шаг 3: Просмотр заблокированных IP
1. Войдите с другого устройства/IP
2. Перейдите в Settings
3. Прокрутите вниз до секции "Security - Blocked IPs"
4. Вы увидите заблокированный IP с информацией:
   - IP адрес
   - Количество попыток
   - Время блокировки
   - Оставшееся время

### Шаг 4: Проверьте счетчик попыток
1. Введите неверный пароль 2-3 раза
2. Вы увидите сообщение: "Осталось попыток: X"
3. При успешном входе счетчик сбрасывается

## Тестирование поиска пользователей

### Шаг 1: Создайте тестовых пользователей
1. Войдите в панель
2. Создайте несколько пользователей с разными именами:
   - test_user_1
   - test_user_2
   - premium_user
   - basic_user

### Шаг 2: Проверьте поиск
1. В поле поиска введите "test"
2. Таблица покажет только пользователей с "test" в имени
3. Введите "premium"
4. Таблица покажет только premium_user
5. Очистите поле - все пользователи снова видны

### Шаг 3: Проверьте пустой результат
1. Введите несуществующее имя "xyz123"
2. Появится сообщение: "No users found matching 'xyz123'"

## Проверка безопасности

### Тест 1: Разные IP адреса
- Блокировка работает независимо для каждого IP
- Если IP1 заблокирован, IP2 может входить нормально

### Тест 2: Успешный вход сбрасывает счетчик
1. Сделайте 3 неудачные попытки
2. Войдите с правильным паролем
3. Счетчик сброшен - можете снова сделать 5 попыток

### Тест 3: Истечение блокировки
1. Дождитесь истечения 15 минут
2. IP автоматически разблокируется
3. Можно снова входить

## Возможные проблемы

### Проблема: Блокировка не работает
**Решение:** Убедитесь, что модуль `ip_blocker.py` импортирован в `app.py`

### Проблема: Поиск не работает
**Решение:** Проверьте консоль браузера на ошибки JavaScript

### Проблема: Не видно заблокированных IP в Settings
**Решение:** 
1. Проверьте, что endpoint `/api/security/blocked-ips` работает
2. Откройте консоль браузера и проверьте ошибки сети

```python
import logging
logging.basicConfig(level=logging.DEBUG)
```

Это покажет все попытки входа и блокировки в консоли.
