# Новые функции - IP блокировка и поиск пользователей

## Реализованные функции

### 1. Блокировка IP после неудачных попыток входа

**Параметры:**
- Максимум попыток: 5
- Временное окно: 5 минут
- Длительность блокировки: 15 минут

**Как работает:**
1. После каждой неудачной попытки входа IP записывается в систему
2. Если за 5 минут происходит 5 неудачных попыток - IP блокируется на 15 минут
3. При успешном входе счетчик сбрасывается
4. Заблокированные IP отображаются в разделе Settings

**Файлы:**
- `ip_blocker.py` - модуль блокировки IP
- `app.py` - интеграция в login endpoint
- `templates/settings.html` - UI для просмотра заблокированных IP

**API endpoints:**
- `GET /api/security/blocked-ips` - получить список заблокированных IP

### 2. Поиск пользователей в реальном времени

**Функциональность:**
- Поиск по имени пользователя
- Мгновенная фильтрация без перезагрузки страницы
- Отображение "No users found" если ничего не найдено

**Файлы:**
- `templates/dashboard_v2.html` - добавлено поле поиска и логика фильтрации

**Как использовать:**
1. Введите имя пользователя в поле поиска
2. Таблица автоматически отфильтруется
3. Очистите поле для отображения всех пользователей

## Настройка параметров блокировки

В файле `ip_blocker.py` можно изменить:

```python
MAX_ATTEMPTS = 5        # Максимум попыток
ATTEMPT_WINDOW = 300    # Окно в секундах (5 минут)
BLOCK_DURATION = 900    # Длительность блокировки (15 минут)
```

## Безопасность

- Блокировка работает на уровне приложения
- Данные хранятся в памяти (сбрасываются при перезапуске)
- Автоматическая очистка истекших блокировок
- Защита от brute-force атак
